# 全库增强搜索插件 (Enhancing Search for EdgeEver)

> 🚀 **打破笔记本边界，秒级定位全应用笔记！** 专为 EdgeEver 打造的全域深度搜索插件，支持多关键词分词、标签提取、创建/修改时间范围过滤、智能高亮摘要上下文以及双栏沉浸式卡片实时预览。

---

## ✨ 核心特性

- 🌐 **全应用全局检索**：突破当前单篇笔记或单个笔记本的局限，一次检索整个工作区所有的历史笔记。
- 🔍 **多维度复合过滤**：
  - **关键词全文检索**：支持多词空格分词，自动计算命中权重（标题 > 标签 > 正文）。
  - **标签筛选**：直接支持 `#标签名` 语法（如 `#技术 react`）或通过界面标签筛选。
  - **时间范围过滤**：快速筛选「全部时间」、「今天」、「最近7天」、「最近30天」。
  - **时间基准切换**：自由切换基于【🕒 修改时间】或【📅 创建时间】进行范围筛选与排序。
- ⚡ **秒级极速索引缓存**：内置高性能内存分词索引，打字即出结果（毫秒级响应）。
- 📑 **双栏卡片沉浸式预览 (Spotlight / Raycast 体验)**：
  - **左侧**：精美卡片列表，展示笔记本徽标、Tags Pills、相对时间、高亮匹配上下文片段 (`<mark>`)。
  - **右侧**：所选笔记即时深度卡片预览，包含元数据详情与 Markdown 正文排版，并在正文中自动高亮搜索词。
- 🎯 **键盘全流程高效操作**：
  - `Cmd / Ctrl + Shift + F`：全局呼出增强搜索弹窗。
  - `↑` / `↓`：在结果卡片列表中丝滑切换选择。
  - `Enter`：立即在主编辑器中打开当前笔记并退出弹窗。
  - `Esc`：平滑退出弹窗。
- 🧩 **无缝统一插件工具坞 (Plugin Dock)**：
  - 自动与【增强导出插件】及【GitHub开源热搜插件】等统一排队，采用弹性纵向排列，绝不互相重叠或遮挡！
  - 同时支持在设置中切换为【左侧边栏底部】或【编辑器顶部工具栏】。

---

## 🛠️ 安装与使用

1. 打开 EdgeEver 客户端 -> 进入 **【设置】** -> **【插件管理】**；
2. 点击 **【从 GitHub 安装】**，输入仓库地址：
   ```text
   https://github.com/zyhcs/edgeever-enhancing-search.git
   ```
3. 安装完成后即可在屏幕右下角插件工具坞看到**蓝色放大镜图标**，或随时按下 `Cmd/Ctrl + Shift + F` 呼出搜索！

---

## ⚙️ 配置项说明

在插件设置中提供丰富的自定义选项：
- **增强搜索入口按钮显示位置**：
  - `🧩 统一插件悬浮工具坞` (自动排队，与其他插件无缝并存，推荐默认)
  - `📁 左侧边栏底部` (与设置齿轮并列，全局常驻且不占正文)
  - `📝 嵌入编辑器顶部工具栏` (仅打开笔记时在标题栏显示)
  - `🚫 隐藏按钮` (纯快捷键唤出)
- **默认搜索排序规则**：相关度优先、最近修改时间、最新创建时间、标题字典顺序。
- **默认检索范围**：全工作区所有笔记 / 优先当前笔记本。
- **启用双栏深度卡片预览**：开启/关闭右侧卡片预览面板。
